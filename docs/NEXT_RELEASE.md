# Next release

1. IndexedDB document store with schema migrations and recovery snapshots.
2. Signed capability manifests and published asset hashes.
3. Evaluation harness with multilingual, mixed-script, domain-term, and privacy corpora.
4. Optional language-specific spelling packs selected after reliable detection.
5. Compact indexed lexicon format to reduce shard transfer and parse cost.
6. Local worker telemetry: cold load, warm latency, memory estimate, and abstention reason.
7. Chrome extension using the same capability contracts with explicit per-site permissions.
8. A versioned evaluation set for summarization, rewrite fidelity, instruction
   adherence, latency, and peak memory on the opt-in 360M model.
9. Same-origin, content-addressed model artifacts with resumable downloads and
   an explicit storage manager.

The structured assistant remains the default until generative quality and
device measurements justify changing it. The 360M profile must remain opt-in,
English-first, and author-reviewed.
